# Каталог базовых упражнений

Финальный каталог только базовых (фундаментальных) упражнений по каждому направлению/тегу. Все упражнения, которые оказались комбинациями, усложнёнными вариантами или узкоспециализированными техниками, удалены из каталога — под каждым разделом отдельно перечислено, что удалено или реклассифицировано и почему. Каждая оставшаяся или добавленная строка подтверждена официальным/авторитетным источником и, где существует, ссылкой на Wikipedia.

- `добавить` — упражнения пока нет в JSON-каталоге, предлагается добавить по итогам аудита.
- `перенести из Meditation` — существующая запись перенесена в Breathwork с сохранением стабильного `key`.
- Во всех строках `availableUntil = null`.
- Источник/Wikipedia = «не применимо» — строка описывает механику приложения (Custom/Other), а не физическое упражнение.
- Источник = «не подтверждено» — отдельную страницу авторитетного источника не удалось найти доступными инструментами исследования за время аудита; упражнение всё равно оставлено как общеизвестный элемент стандартной практики (тренерский спот-чек не выявил в нём признаков комбинации/узкой специализации).
